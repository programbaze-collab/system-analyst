# SQL-запросы к модели данных из ТЗ

Запросы к базе обмена с 1С из [ТЗ](../tz-1c-exchange/tz-1c-exchange.md) (раздел 6, модель данных). Каждый запрос отвечает на вопрос бизнеса или поддержки.

- [schema.sql](schema.sql) — таблицы: товары, склады, остатки, поставщики, сопоставления, журнал обмена;
- [seed.sql](seed.sql) — тестовые данные;
- [queries.sql](queries.sql) — запросы с комментариями.

Синтаксис стандартный, запросы проверены в SQLite и подходят для PostgreSQL. «Сейчас» в запросах — 27.10.2026 12:00, дата задана явно, чтобы результаты были воспроизводимыми.

Запуск в SQLite:

```bash
sqlite3 :memory: ".read schema.sql" ".read seed.sql" ".mode table" ".read queries.sql"
```

## Запросы и результаты на тестовых данных

| № | Вопрос | Что используется |
| --- | --- | --- |
| 1 | Цена «от» и общий остаток каждого товара в каталоге | LEFT JOIN, GROUP BY, MIN с CASE, COALESCE |
| 2 | Активные товары, которых нет в наличии | NOT EXISTS |
| 3 | Самый дешёвый склад для каждого товара | оконная функция ROW_NUMBER |
| 4 | Товары с разницей цены между складами больше 10% | GROUP BY, HAVING |
| 5 | Один артикул у разных производителей | COUNT(DISTINCT), HAVING |
| 6 | Поставщики с устаревшим прайсом | LEFT JOIN, условие по дате |
| 7 | Очередь ручной проверки по поставщикам | условная агрегация SUM(CASE) |
| 8 | Пакеты с ошибками за сутки и доля отклонённых | вычисляемые поля, фильтр по периоду |
| 9 | Самые частые ошибки обмена | JOIN, GROUP BY, сортировка |
| 10 | Ошибки, которые повторяются из пакета в пакет | COUNT(DISTINCT), HAVING |
